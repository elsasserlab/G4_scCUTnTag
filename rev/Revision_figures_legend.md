# Revision Figures — Legend and Derivation Notes

The revision/rebuttal panels (F01–F30) answer reviewer questions about G4 signal reproducibility, functional annotation, independence from chromatin accessibility, and QC of the neural datasets. Each panel produced by R scripts under `rev/`.

## Shared data sources

- **mESC-MEF single-cell G4 scCUT&Tag (GSE291468, GSM8836088)** — cluster-specific MACS2 narrowPeak sets (`GSM8836088_cluster_0_peaks.narrowPeak`, `GSM8836088_cluster_1_peaks.narrowPeak`), pseudobulk RPGC bigWigs (`cluster0_RPGC.bw`, `cluster1_RPGC.bw`), Seurat object
- **Bulk G4 CUT&Tag (GSE291468)** — bulk mESC replicates (GSM8836082, GSM8836083) and bulk MEF/3T3 replicates (GSM8836084, GSM8836085) as broadPeak calls and RPGC bigWigs
- **Sorted GFP+ brain G4 (GSE291468, GSM8836086)** — predicted-astrocyte and predicted-non-astrocyte RPGC bigWigs (`GSM8836086_Predicted_Astrocytes_RPGC.smooth150.bw`, `GSM8836086_Predicted_non-Astrocytes_RPGC.smooth150.bw`), label-transfer outputs
- **Unsorted mouse-brain G4 (GSE291468, GSM8836087)** — Seurat object, cluster-specific narrowPeak sets and RPGC bigWigs
- **mESC ATAC-seq (GSE149080, GSM4661960)** and **3T3 ATAC-seq (GSE211123, GSM6451000)** — matched bulk accessibility narrowPeak sets and RPGC bigWigs
- **Published 3T3 G4 CUT&Tag (GSE217860, GSM6729104–06)** — three replicates (aligned bigWigs) used as independent bulk benchmark
- **Brain snATAC reference (GSE198467)** — `GSE198467_ATAC_Seurat_object_clustered_renamed.Rds`, clustered Seurat object with 15 named cell types
- **Gene expression reference** — `gene_level_TPM.tsv` (mESC/MEF TPM table), `gene_level_RPKM.xlsx` (Chronis et al. GSE90894), mm10 GENCODE annotation GTF (`mm10_.annotation.gtf.gz`)
- **G4 references** — pqsfinder PQS predictions (`PQS_scores.mm10.bed`, `PQS_scores.mm10.bw`), experimentally validated eG4 catalog (`eG4_catalog.bed`)
- **RefSeq annotation** — `refGene.tss.1kb.mm10.bed` (TSS ±1kb)

## Panels

**F01 — Genomic feature distribution (bulk vs scCUT&Tag).** Fraction of G4 peaks assigned to genomic features (promoter TSS ±2kb, 5′ UTR, 3′ UTR, CDS exon, intron, intergenic) for bulk-consensus vs single-cell pseudobulk peaks in mESC and MEF. Bulk consensus built from two bulk replicates (GSM8836082/83 mESC; GSM8836084/85 MEF) with `bedscout::loci_consensus(min_consensus=2)` retaining max signalValue; pseudobulk = GSM8836088 cluster peaks (MACS2 narrowPeak). Features derived from mm10 GENCODE GTF (`mm10_.annotation.gtf.gz`); each peak classified by midpoint using `GenomicRanges::overlapsAny()` priority cascade (promoter → 5′UTR → 3′UTR → CDS exon → intron → intergenic). Plotted as grouped + stacked bar charts. Tools: bedscout, GenomicRanges, rtracklayer, data.table, ggplot2, scales. Outputs: `feature_distribution.csv`, `feature_distribution_grouped.pdf`, `feature_distribution_stacked.pdf`, per-cell-type feature TSVs (`mESC_pseudobulk_features.tsv`, `MEF_pseudobulk_features.tsv`, `mESC_bulk_consensus_features.tsv`, `MEF_bulk_consensus_features.tsv`).

**F03 — Distance-to-TSS distribution.** Signed distance of each bulk-consensus and pseudobulk G4 peak to nearest transcript TSS (mm10 GENCODE), shown as binned bars per cell type. Nearest TSS identified with `GenomicRanges::distanceToNearest()` from peak midpoints to GENCODE TSS (± strand). Distances binned (−5 kb to +5 kb in 500 bp bins) and plotted as percentage per bin. Same peak inputs as F01; demonstrates promoter enrichment of bulk and single-cell G4 peaks. Tools: GenomicRanges, rtracklayer, data.table, ggplot2, scales. Outputs: `distance_to_TSS_per_peak.csv`, `distance_to_TSS_binned.csv`, `distance_to_TSS_binned.pdf`.

**F04 — Stratified recovery of bulk peaks.** For each cell type, bulk-consensus peaks binned into signal deciles (signalValue from broadPeak) and percentage recovered in scCUT&Tag pseudobulk plotted per decile, plus Jaccard/overlap statistics. Recovery = % of bulk peaks in each decile overlapping any pseudobulk peak (`GenomicRanges::overlapsAny()`). Jaccard index computed with `bedscout::jaccard_index()`; total base-pair overlap with `bedscout::total_bp_overlap()`. Inputs as F01; demonstrates higher-signal bulk peaks more likely recovered in scCUT&Tag. Tools: bedscout, GenomicRanges, data.table, ggplot2. Outputs: `stratified_recovery.csv`, `stratified_recovery.pdf`, `overlap_stats.csv`.

**F05 — G4 promoter signal vs gene expression.** Mean G4 RPGC signal at gene promoters (TSS ±2kb) of two scCUT&Tag clusters plotted against matched-cell-type RNA-seq expression deciles (mESC/MEF TPM from `gene_level_TPM.tsv`). Promoters defined as TSS ±2kb from mm10 GENCODE GTF (`mm10_.annotation.gtf.gz`). Mean bigWig signal per promoter computed with `rtracklayer::summary(BigWigFile, type="mean")`. Genes binned into expression deciles (TPM). Mean G4 signal per decile plotted with SEM bars. Cluster pseudobulk RPGC bigWigs: GSM8836088_cluster0 (MEF), GSM8836088_cluster1 (mESC); expression matched by cell type. Tools: rtracklayer, GenomicRanges, data.table, ggplot2, scales, patchwork. Outputs: `gene_level_G4_vs_expression.tsv`, `decile_summary.csv`, `decile_G4_by_expression.pdf`, `cross_correlation_table.csv`.

**F06 — G4–expression relationship (overlay and metagene).** Left: both clusters overlaid as mean promoter-signal vs expression-decile lines with SEM ribbons (same data as F05). Right: metagene profile of G4 signal ±3kb around TSS stratified by expression quintile. Metagene computed with `bedscout::plot_bw_profile()` in 100bp bins, stratified by gene expression quintiles. Tools: rtracklayer, GenomicRanges, bedscout, data.table, ggplot2, patchwork. Outputs: `plot3_overlaid_lines.pdf`, `plot4_metagene_profile.pdf`, `metagene_data.csv`.

**F09 / F10 — GO Biological Process of cell-specific G4 peaks.** Cluster-discriminating (unique) peaks extracted from bulk-vs-cluster overlap analysis: mESC-specific = bulk mESC (GSM8836082 broadPeak) overlapping scG4 cluster 1 (GSM8836088_cluster_1_peaks.narrowPeak) but not cluster 0; MEF-specific = bulk MEF (GSM8836084 broadPeak) overlapping scG4 cluster 0 but not cluster 1 (Fig 1D logic, `GenomicRanges::overlapsAny()`). Outputs: `F30_scatter_union_intersection.pdf`, `F30_intersection_data.csv`, `F30_union_data.csv`.
