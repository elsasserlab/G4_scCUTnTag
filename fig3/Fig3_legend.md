# Figure 3 — Legend and Derivation Notes

**Figure 3: Reliability-based annotation enhances cell-type assignment of G4 scCUT&Tag data and identifies astrocyte-specific G4 signals.**

## Data sources

- **Sorted GFP+ brain G4 scCUT&Tag (GSE291468, GSM8836086)** — `GSM8836086_GFPpos_Seurat_object.Rds`, gene-activity (GA) assay, peak assay, `GSM8836086_GFP_sorted_mouse_brain/CellRanger/fragments.tsv.gz`
- **Brain scRNA-seq reference (GSE163484, Bartosovic et al.)** — processed Seurat object with cell_type annotations
- **scBridge co-embedding** — precomputed outputs: `umap_coembedded.csv`, `scbridge_predictions.csv` (barcodes_Astrocytes.tsv, barcodes_non_AST.tsv), `scbridge_reliability.csv`
- **Cicero co-accessibility** — `results/cicero/cicero_browser_example-AST_spec.pdf`
- **Mouse gene annotation** — EnsDb.Mmusculus.v79
- **PQS scores** — `PQS_scores.mm10.bw`

Produced by `fig3/fig3.R`, with Cicero analysis in `fig3/cicero.R`.

## Panels

**Panel A — scBridge joint-embedding UMAP.** 2×2 grid showing four views on single co-embedding of GFP+ G4 cells (GSM8836086) and scRNA-seq reference (GSE163484). UMAP coordinates from scBridge precomputed output (`umap_coembedded.csv`). Four views: (top-left) reference cell types (scRNA-seq cells only), (top-right) data modality (scRNA-seq vs G4 scCUT&Tag), (bottom-left) transferred predictions for G4 cells (from `scbridge_predictions.csv`, prediction_clean column), (bottom-right) integration reliability score (from `scbridge_reliability.csv`, viridis scale 0-1). Tools: Seurat, ggplot2. Output: `panel_A_coembedded_UMAPs.pdf`.

**Panel B — Astrocyte (AST) vs non-AST differential G4.** 2×2 grid: **B1** (top-left): UMAP of GFP+ G4 cells colored by AST/non-AST status from scBridge predictions (Prediction_clean=="AST" vs all other reliable labels). **B2** (top-right): volcano plot of differential G4 gene-activity scores (full gene body) between predicted AST and non-AST cells, computed with Seurat `FindMarkers()` (logistic regression test on GA assay, latent.vars="peak_region_fragments", logfc.threshold=0, only.pos=FALSE). **B3** (bottom-left): volcano plot of differential G4 signal at promoter-proximal peaks (TSS ±2kb), computed with Seurat `FindMarkers()` (Wilcoxon test on log-normalized peak counts, assay="peaks", normalization.method="LogNormalize"). **B4** (bottom-right): volcano plot of differential scRNA-seq expression (AST vs non-AST cells from reference), computed with Seurat `FindMarkers()` (Wilcoxon test, assay="RNA", logfc.threshold=0). All volcanoes: thresholds |log2FC|>0.5, adj.P<0.05; highlighted genes (*Tnik*, *Pitpnc1*, *Pbx1*, *Nwd1*) shown with ggrepel labels. B4 highlights genes that are AST-up in either B2 or B3. Tools: Seurat, ggplot2, ggrepel, data.table. Outputs: `panel_B_AST_vs_nonAST.pdf`, `panel_B_diff_GA_full_AST_vs_nonAST.csv`, `panel_B_diff_G4peaks_AST_vs_nonAST.csv`, `panel_B_diff_G4peaks_promoters_AST_vs_nonAST.csv`, `panel_B_diff_RNA_AST_vs_nonAST.csv`.

**Panel C — Coverage at differential-G4-promoter-peak genes.** Genome browser coverage plots for 11 curated genes (*Plcl1*, *Nwd1*, *Gli2*, *Smad9*, *Tmem74*, *Gm25493*, *Scarna17*, *Acaa2*, *Stambpl1*, *App*, *Rsg1*) with AST-up G4 peaks at promoter (from Panel B3). Cell groups: predicted AST (183 cells from barcodes_Astrocytes.tsv) vs predicted non-AST (2521 cells from barcodes_non_AST.tsv). Each window: anchor peak ±10 kb upstream / +35 kb downstream (strand-aware), or TSS if no promoter peak exists. Tracks shown: fragment coverage from GSM8836086 CellRanger fragments (Signac `CoveragePlot()` with peaks=TRUE, annotation=TRUE), bigWig coverage tracks (predicted AST RPGC, predicted non-AST RPGC, PQS score). BigWig inputs: `GSM8836086_Predicted_Astrocytes_RPGC.smooth150.bw`, `GSM8836086_Predicted_non-Astrocytes_RPGC.smooth150.bw`, `PQS_scores.mm10.bw`. Tools: Signac `CoveragePlot()`, rtracklayer. Outputs: `panel_C_coverage.pdf`, `panel_C_selected_genes.csv`, `GSM8836086_all_peaks.bed`, `GSM8836086_AST_specific_peaks.bed`, `GSM8836086_nonAST_specific_peaks.bed`, `GSM8836086_AST_vs_nonAST_log2fc.bed`, `GSM8836086_AST_vs_nonAST_per_peak.tsv`.

**Panel D — Astrocyte-specific gene expression feature plots.** UMAP feature plots of normalized scRNA-seq expression for four highlighted astrocyte genes (*Tnik*, *Pitpnc1*, *Pbx1*, *Nwd1*) on scRNA-seq reference cells (GSE163484), plotted on same co-embedding coordinates as Panel A. Tool: Seurat `FeaturePlot()`. Output: `panel_D_featureplots.pdf`.

**Panel E — Cicero co-accessibility browser tracks.** Candidate regulatory-element browser views connecting astrocyte-specific G4 peaks with mouse-brain cCREs (cCREs with H3K27ac signal above 75th percentile from Li et al.). Generated by `fig3/cicero.R`: Cicero co-accessibility model (`cicero::run_cicero()`) on G4 peaks, example browser tracks rendered for AST-specific peaks. Output copied from Cicero analysis. Output: `panel_E_cicero_tracks.pdf`.
